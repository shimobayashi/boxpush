# 演出の方向性

何を狙って演出を組んでいるか、どこに力を入れてどこを抑えているか、
調整したくなったときにどの数字を触ればいいかをまとめる。

全体の仕様は [design.md](design.md) にある。ここはその「演出」の節を詳しく書いたもの。

## 1. 狙い

**遊んでいて気持ちが高ぶること。** 見た目の上品さより、手応えの強さを取る。

最初は「箱が入った瞬間」と「面クリア」の 2 か所に演出を置いただけだった。
それだと物足りないことが遊んでみて分かり、パチスロの演出構造を借りて組み直した。

パチスロの演出の核を分解すると、こうなる。

| 仕組み | このゲームでの形 |
| --- | --- |
| 結果が出る前に期待を吊り上げる | あと 1 手で入るときの予告 |
| タメてから解放する | 吸い込み → 静止 → 爆発 |
| 数字が増える | 手数の数え上げ、残り個数 |
| まれに特別なものが出る | **入れていない**（見送った案） |

**結果が出たあとにしか演出が無いと、気持ちが高ぶる時間が生まれない。**
これが一番大きな気づきだった。予告と溜めは、押す前と押した後の「間」を作るためにある。

## 2. 山場をどこに置くか

**面の最後の 1 個だけを特別扱いにする。** 途中の箱は軽く扱う。

| | 途中の箱 | 最後の 1 個 |
| --- | --- | --- |
| 予告 | 出さない | 出す |
| 溜め | なし。押した瞬間に弾ける | 吸い込み 0.6 秒 + 静止 0.18 秒 |
| 爆発の強さ | 2.6 → 3.4 → 4.2 と積み上がる | 6（固定） |
| 画面フラッシュ | 金色、0.42 → 0.54 → 0.66 | 白、最大 |
| 音 | 音階が 1 つずつ上がる | 和音で解き放つ |

はじめは予告も溜めもすべての箱に出していた。
箱 3 個の面では合計 2.4 秒を溜めに費やすことになり、
「テンポよく次々クリアする」という方針と真っ向からぶつかった。
途中の箱でも予告が出ると、ここぞという感じも薄れる。

**爆発の強さだけは途中の箱でも積み上がる。**
1 面で箱が入るのは 1〜3 回しかないので、最後だけにすると気持ちよさの回数が減りすぎるため。

## 3. 爆発の大きさの決まり方

`strength` という 1 つの数字が、爆発のすべてを支配する。

```ts
// src/main.ts の onFit()
const strength = game.cleared ? 6 : 2.6 + fitCount * 0.8
```

`fitCount` はその面でこれまでに入れた箱の数（面が変わると 0 に戻る）。

この 1 つの数字が、`effects.burst()` の中で 6 つの値に同時に効く。

| 要素 | 式 |
| --- | --- |
| 粒の数 | `18 × strength` |
| 粒の速さ | `× (0.8 + strength × 0.4)` |
| 粒の寿命 | `× (0.8 + strength × 0.3)` |
| 粒の大きさ | `× (0.8 + strength × 0.3)` |
| 光の筋の本数 | `6 × strength` |
| 輪の太さ・画面の揺れ | `strength` に比例 |

数が増えると同時に一つ一つが大きく速く長く生きるので、
**strength を n 倍すると体感はおよそ n² 倍**になる。強さを変えるならこの 1 行を触る。

## 4. 数字の一覧

すべて `src/main.ts` の先頭にまとめてある（入力だけ `src/ui/input.ts`）。

| 定数 | 値 | 何に効くか |
| --- | --- | --- |
| `STEP_SECONDS` | 0.085 | 1 歩を描き切る時間 |
| `FIT_SLOWDOWN` | 7 | 最後の 1 個が吸い込まれる遅さの倍率 |
| `HIT_STOP_SECONDS` | 0.18 | 吸い込み切ってから爆発までの静止 |
| `CLEAR_SECONDS` | 1.5 | クリア演出を見せる時間 |
| `JUST_FIT_SECONDS` | 0.4 | 入った箱を強く光らせる時間 |
| `TRAIL_SECONDS` / `TRAIL_LIMIT` | 0.5 / 8 | 人が通った跡の残り方 |
| `CONFETTI_WAVES` | 1.15, 0.85, 0.5 | 紙吹雪を追加で降らせる残り時間 |
| `CONFETTI_TAIL_SECONDS` | 0.25 | 紙吹雪が次の面に残る時間 |
| `STEP_RATIO` | 0.55 | 1 歩と見なす指の移動距離（マスの何割か） |

押してから爆発までは `STEP_SECONDS × FIT_SLOWDOWN + HIT_STOP_SECONDS` で約 0.8 秒。

## 5. 触ってみて分かったこと

演出は数字をいじるだけでは決まらない。実際に遊んで初めて分かったことを残す。

**すべての箱に溜めを入れるとテンポが死ぬ。**
一つ一つは気持ちよくても、積み重なると「待たされている」に変わる。
溜めは面に 1 回だけにする。

**演出を途中で打ち切ると不自然に見える。**
紙吹雪が次の面まで降り続けるのを、面が始まった時点で寿命を詰めて止めようとしたら、
そこで見た目が急に変わって余計に目立った。
**撒く時点で寿命を決めておき、あとは同じ計算で自然に消えるのに任せる**のが正解だった。

**同時に鳴る音は、細いものから埋もれる。**
予告の音が聞こえないという指摘を受けて調べたら、音自体は鳴っていた。
押した音・残り 1 個の合図・予告の 3 つが同じ瞬間に重なり、一番細い予告が消えていた。
**鳴らす時間をずらし、波形を厚くする**（sine より triangle）ことで解決した。
音が聞こえないときは、まず他の音と重なっていないかを疑う。

**「なぞっている指」は「触れた」ではない。**
クリア演出を飛ばす操作を画面に触れることに割り当てたら、
なぞってクリアした指がそのまま触れていて、演出が一瞬も見えずに飛んだ。
面が切り替わるときは指の追跡を切る。

## 6. 入れていない案

提案したが、今のところ手を付けていないもの。やるとしたらこの辺り。

| 案 | 中身 |
| --- | --- |
| スコアの上乗せ | 箱を入れると数字が飛び出して回りながら加算される。連続で倍率がつく |
| まれに出る特別演出 | 20 回に 1 回くらい、虹色の爆発と専用の音になる。意味は無くてよい |
| 連続クリアの見せ方を強くする | 今は背景が色づくだけ。「3 連」のような表示や、段階ごとの専用演出 |
| 通常時の BGM | 今は効果音だけ。残り 1 個で曲調が変わるような作り |

## 7. 抑えていること

派手にする方向で進めているが、次の 2 つは崩さない。

- **盤面が読み取れること。** 演出で箱や穴が見えなくなるなら、その演出は行きすぎ。
  紙吹雪を次の面に長く残さないのはこのため
- **押してから反応が返るまでの速さ。** 溜めるのは面の最後だけ。
  途中の箱は押した瞬間に弾ける
